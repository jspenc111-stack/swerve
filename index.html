    Installing Swerve

    To install: in Chrome, tap ⋮ → Add to Home screen → Install.

    Chrome says it's already installed, but it won't open? A broken copy is left on the phone. Remove it:

    1. Open the Play Store → tap your profile picture → Manage apps & device → Manage. Find Swerve and uninstall it.
    2. If it isn't there: Settings → Apps → See all apps, switch the list to Archived or Disabled, and uninstall Swerve.
    3. Restart the phone, open this page in Chrome and install again.

    Avoid Chrome's “Clear site data” for this site: other apps on the same web address would lose their saved data too.
